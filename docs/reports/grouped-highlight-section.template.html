Experiment design and limits

Three available Groq text models use the same captured hall-day menus. Program-first identifies meal services before ranking. Cluster-first identifies mains before grouping. The minimal contract removes component bookkeeping and resolves singleton names from the source. Inventory-first is a focused two-hall pilot with two inference stages. Exploratory revisions remain separate rounds and failures remain visible.

GPT-OSS models use low reasoning and a 2,000-token completion allowance. Medium reasoning is tested separately for 120B. Qwen uses no reasoning and a 1,000-token allowance after this account rejected larger requests. This is a practical configuration comparison, not equal inference compute. Earlier quota errors remain in round 1. A pilot changes both inventory effort and schema complexity, so any gain cannot be attributed to one factor alone.
